# Ανεργία στη Δυτική Μακεδονία: τι, γιατί, τι σημαίνει, τι κάνουμε

Ανάλυση σε Excel με δεδομένα Eurostat και ΕΛΣΤΑΤ (2021–Β΄ 2026), 13 περιφέρειες.
Όλοι οι αριθμοί είναι τύποι κανένας δεν είναι πληκτρολογημένος.

## 1. Τι έγινε
- 2025: ανεργία ΔΜ 15,3% έναντι 8,9% στην Ελλάδα και 6,0% στην ΕΕ-27, η υψηλότερη των 13 περιφερειών.
- Β΄ 2026: 12,7% έναντι 7,9% στη χώρα (2η υψηλότερη).

## 2. Γιατί έγινε (δέντρο: ανεργία ← απασχόληση και συμμετοχή)
- Απασχόληση 20–64 το 2025: 61,6% έναντι 71,0%, η χαμηλότερη των 13.
- Β΄ 2026: η απασχόληση ανά πληθυσμό 15+ υστερεί κατά 8,3 μ.π.· λογιστικά,
  ~73% αντιστοιχεί στη χαμηλότερη συμμετοχή και ~27% στην ανεργία.

## 3. Τι σημαίνει
- Η ανεργία υποτιμά το πρόβλημα: η ΔΜ είναι τελευταία σε συμμετοχή και απασχόληση.
- Οι γυναίκες έχουν διπλάσια ανεργία από τους άνδρες (21,2% έναντι 10,8%, 2025).
- Οι ετήσιες μεταβολές είναι θορυβώδεις (όριο 3,9 μ.π., 90ο εκατοστημόριο)·
  κρίνω την τάση, όχι μεμονωμένα έτη.

## 4. Τι κάνουμε τώρα
- Κύριος δείκτης: απασχόληση 20–64, όχι μόνο ανεργία.
- Ζητάμε στοιχεία ΔΜ ανά ηλικία, εκπαίδευση, κλάδο και αποτελέσματα προγραμμάτων ΔΥΠΑ.
- Πρόταση πιλοτικού 12 μηνών για άνεργες γυναίκες (φύλλο «Πιλοτικό_Πρόγραμμα»),
  υπό την προϋπόθεση των παραπάνω δεδομένων.

## Όρια
Μικρό δείγμα ΕΕΔ σε επίπεδο περιφέρειας· δεν υπάρχουν στοιχεία ανά κλάδο/ηλικία·
δεν υπάρχει μοντέλο κόστους-οφέλους. Κάποιες τιμές δεν έχουν διασταυρωθεί
με πρωτογενή πηγή (βλ. «Πηγές_Όρια»).
